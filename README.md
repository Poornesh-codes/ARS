# Activity Recognition System

A machine learning project that recognizes human
activities using smartphone motion sensor data.

## Objective

Classify six human activities using accelerometer
and gyroscope readings.

## Activities

- Walking
- Walking Upstairs
- Walking Downstairs
- Sitting
- Standing
- Laying

## Dataset

UCI Human Activity Recognition Using Smartphones.

## Models

- Random Forest
- 1D Convolutional Neural Network
- LSTM

## Development Environment

- Python
- Scikit-learn
- TensorFlow
- Google Colab
- Git and GitHub
